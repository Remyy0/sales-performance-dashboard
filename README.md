# Sales Performance Dashboard

An interactive sales performance dashboard developed using **Microsoft Excel** to analyze sales data across brands, branches, product categories, and payment methods.

## Project Overview

The project transforms raw sales data from multiple related tables into a structured data model and interactive dashboard for sales performance analysis.

The dataset includes:

- Brands
- Branches
- Customers
- Payment Methods
- Products
- Sales 2023
- Sales 2024

## Data Preparation & Modeling

- Cleaned and transformed data from multiple tables using **Power Query**.
- Integrated the 2023 and 2024 sales data for analysis.
- Built a relational data model using **Power Pivot**.
- Created calculated columns and measures using **DAX**.
- Established relationships between sales data and supporting tables.

## Dashboard

Built an interactive dashboard using:

- PivotTables
- Pivot Charts
- Slicers
- KPIs

The dashboard enables analysis of sales performance across different brands, branches, product categories, payment methods, and sales periods.

## Tools & Technologies
